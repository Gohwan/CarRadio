CarRadio 상대 차량 테스트

이 PC의 중계 서버에 연결하는 테스트 기기입니다. 실제 차량이 아닙니다. 워키토키 참여 후에는 상대 목소리가 바로 재생됩니다. 별도의 녹음 파일 메시지는 재생 버튼으로 듣습니다.

앱의 메시지 음성 읽기를 먼저 끄고, 같은 채널과 가까운 좌표로 연결하세요.

미연결
연결 설정

기본값은 에뮬레이터 좌표 예시입니다. 앱의 설정에 표시된 위도·경도와 맞추세요.

번호는 직접 입력한 정보이며 차량 인증을 하지 않습니다. 입력번호·설정한 위치·메시지를 이 PC의 서버와 수신 기기에 공유합니다. 메시지·음성은 서버에서 최대 2분, 연결 정보는 갱신 중단 후 최대 15초 유지됩니다.

주변 기기

  • 연결 후 확인할 수 있습니다.

워키토키

같은 채널·반경 안에서 워키토키에 참여한 기기끼리 목소리를 주고받습니다. 참여하면 받은 음성이 바로 재생됩니다. 한 번에 한 명, 최대 15초이며 이 창을 벗어나면 종료됩니다.

서버에 연결한 뒤 참여하세요.

말하기를 시작하면 입력 크기가 표시됩니다.

테스트음은 440Hz 소리입니다. 상대도 워키토키에 참여한 상태에서 사용하세요. 가상 자동응답 차량은 워키토키에 참여하지 않습니다.

발언을 끝낸 뒤 같은 기기는 2초 기다립니다. 음소거는 목소리에만 적용되고 문자 신호는 계속 받습니다. 나갔다 다시 참여하면 음소거가 해제됩니다.
